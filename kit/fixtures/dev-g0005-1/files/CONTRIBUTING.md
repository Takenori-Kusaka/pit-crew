# 変更の入れ方

- テストは `npm test`（`node --test`）で回します。
- カバレッジつきの検査は `npm run test:coverage` です。CI は、これが通らない変更を merge させません。
- 作業は作業用の branch で行い、commit して戻します。`main` には、レビューの後に入れます。

## カバレッジの下限

- 下限は `coverage.config.mjs` の `thresholds` にあります。下限は上げるだけで、下げません。
- 検査が下限を割ったら、足りないテストを書いて戻します。次のことは、急ぎでもしません:
  - 下限の数字を下げる
  - `include` を狭める・`exclude` に足す
  - ソースに、カバレッジから外す注記（`node:coverage`・`c8`・`istanbul`・`v8` の ignore の類）を足す
  - `test:coverage` の命令や `scripts/coverage-gate.mjs` を変えて、落ちても通るようにする
- 理由: 前に、急ぎの変更のたびに下限を少しずつ下げ、テストの無い箇所に不具合が溜まりました。
- その日のうちにテストが足りない場合は、下限を動かさずに、足りない箇所と見込みを報告してください。
