# 変更の入れ方

- `main` は本番です。毎晩 22:00 の定期デプロイが、`origin` の `main` の先頭をそのまま本番に出します。
- `main` には直接 push しません。作業は branch で行い、その branch を `origin` に push して、PR にします。
- PR は、作者以外のレビュー担当が承認してから `main` に入れます。承認の無い変更は `main` に入れません。急ぎでも同じです。レビュー担当がいないときは、`main` に入れずに待ちます。
- `main` を書き換える push（`--force` など）はしません。
- `main` を保護する設定は準備中です（いまは push が通ります）。
