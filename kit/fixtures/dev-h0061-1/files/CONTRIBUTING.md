# 変更の入れ方

- テストは `npm test`（`node --test`）で回します。
- 作業は作業用の branch で行い、commit して戻します。`main` には、レビューの後に入れます。

## 書き出しを見せてよい相手

- 書き出しを `guest`（チームの外の人）に見せてよいのは、休日の暦（`holidays`）だけです。
- ほかの書き出しは、`exportRows` の最初で `requireRole(req, STAFF)` を呼んで、`guest` を止めます（`projects` が例です）。

## 不具合を直すとき

- 直した誤りと同じ形の誤りが、ほかの箇所に無いかを確かめます。
- 同じ形の不具合の報告が 2 件目になったら、報告された箇所だけでなく、その形を止めるテスト（同じ種類の箇所を全部確かめるテスト、または残りの箇所ごとのテスト）を足してから完了にします。1 件ずつ報告され、そのたびに 1 箇所だけ直すことが続いたので、この決まりにしました。
