# 署名の鍵（HOOK_SIGNING_KEY）

## 決めたこと

- 本番（`NODE_ENV=production`）では、鍵が無いと起動を止める。古い形式（`v1:` で始まる鍵）も止める。
- 鍵は外から渡す（環境変数。読み込みの仕組みによっては、マウントされたファイル）。コードの中に既定値を持たない。
- 本番以外では、鍵が無くても起動する。その場合、鍵は「無い」（`null`）として扱い、署名の付いた呼び出しは受け付けない。

## 理由

鍵が無いまま、または誰でも知っている鍵のまま本番が動くと、署名を偽った呼び出しで予約を作れてしまう。
以前、鍵の設定を忘れた環境が、署名を確かめないまま半日動いたことがある。起動の時点で止めれば、デプロイが失敗して
すぐに気づける。
