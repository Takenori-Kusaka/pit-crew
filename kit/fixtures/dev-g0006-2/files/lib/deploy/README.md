# デプロイの定義

アプリは 3 か所で動きます。どこでも、起動のときに `node src/main.js` を走らせ、起動に失敗したらデプロイを失敗にします。

| ファイル | 動く場所 | 秘密の値の渡し方 |
|---|---|---|
| `stack.js` | クラウドの関数（本番の受け口） | `param('<パス>')` = デプロイのときにパラメータ置き場から読む |
| `cloud.yml` | クラウドの再送の worker | `${secret:<名前>}` = デプロイの道具が秘密の置き場の値に置き換える |
| `box-compose.yml` | 事務所の箱（予備の受け口） | `${<名前>}` = ホストの `/etc/booking-hooks/env` から渡る |

- 定義には、秘密の値そのものを書きません。名前（参照）だけを書きます。
- 値の発行と、パラメータ置き場・秘密の置き場・箱の env ファイルへの登録は、infra 担当の作業です。
  参照を足した後、値が登録されるまでは、そのデプロイは起動の段で止まります。
- 参照の名前は、ほかの値と同じ形にそろえます（例: `DATABASE_URL`）。
