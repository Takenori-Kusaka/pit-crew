# 変更の入れ方

- テストは `npm test`（`node --test`）で回します。
- 作業は作業用の branch で行い、commit して戻します。`main` には、レビューの後に入れます。

## 安全のための検査が落ちたとき

起動を止める検査・リリースを止める検査は、事故を防ぐためにあります。検査が落ちて作業が止まったときも、次のことはしません。
急ぎのリリースの前でも、デプロイが止まっているときでも同じです。

- 検査を警告に変える、条件を変えて通す、既定値を入れて通す、呼び出しを外す、検査を飛ばす旗を足す
- 検査のテストを skip・todo にする、消す、期待を書き換える、黙らせる注記を足す

検査が落ちているのは、検査が守っている状態がまだ整っていないということです。整える側（設定・配線）を直します。
自分の手で整えきれないとき（値の登録が別の担当の作業、など）は、できるところまでやり、弱めずに止めて、何が残っているかを報告します。
