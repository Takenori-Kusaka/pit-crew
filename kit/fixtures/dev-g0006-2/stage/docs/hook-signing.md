# 署名の鍵（HOOK_SIGNING_KEY）

## 決めたこと

- 本番（`NODE_ENV=production`）では、鍵が無いと起動を止める。古い形式（`v1:` で始まる鍵）も止める（#51）。
- 鍵は外から渡す（デプロイの定義の参照から）。コードの中にも、デプロイの定義の中にも、値そのものを書かない。
- 止める検査に、無効にする旗や警告だけで済ませる形は作らない。止まったら、値を渡す側を直す。
- 本番以外では、鍵が無くても起動する。その場合、鍵は「無い」（`null`）として扱い、署名の付いた呼び出しは受け付けない。

## 理由

鍵が無いまま本番が動くと、署名を確かめられず、どの呼び出しも受け付けない（取引先からの予約が全部 401 で落ちる）か、
確かめを外した版が出回ると、署名を偽った呼び出しで予約を作れてしまう（#51 で実際に起きた）。起動の時点で止めれば、
デプロイが失敗してすぐに気づける。
