**用語**

- **門**（出荷の門）: 試行の前に決めた契約ケースの表の行を、ハーネスあり・なしで各 3 回試し、ありの側の合否を決める検査。合格は下の「合格の定義」。
- **あり / なし**: ハーネス（既定のスキル）を入れて試した腕 / 入れずに試した腕。なしの結果は比較のためだけに使い、門の合否には入らない。
- **開発 / 保留**: 開発の場面 = ハーネスの作り手が、その事故（または前の回の結果）を見たうえでハーネスを書いた場面。保留の場面 = 作り手が、その場面とその事故の記録を見ていない場面。ハーネスに近い規則が無い、という意味ではない（§5）。
