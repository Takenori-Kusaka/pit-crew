# relay

Bash toolkit for the parcel-relay operator: deliveries to partners, the nightly export, notifications, the ledger and the audit log.

- Tools: bin/
- Helpers: lib/<domain>/*.sh (sourced by the tools)
- Decisions: docs/adr/README.md
- Operations: docs/runbook.md
- Changes: CHANGELOG.md
- Tests: `bash scripts/verify.sh`
