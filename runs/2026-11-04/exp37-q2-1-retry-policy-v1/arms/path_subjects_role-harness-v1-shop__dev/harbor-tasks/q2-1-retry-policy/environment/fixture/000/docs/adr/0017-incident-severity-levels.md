# ADR-0017: Incident severity levels

| | |
|---|---|
| Status | accepted |
| Date | 2025-09-26 |
| Supersedes | - |

## Context

Every page was "urgent".

## Decision

Three levels: S1 partner-visible outage (page), S2 degraded (ops channel within 15 min), S3 cosmetic (next shift).

## Consequences

The runbook escalation section follows these levels.
