### F0 受け付け

**目的**: 差し戻しを拾い、HEAD を固定し、指摘を全部開いて、1 件ずつ 直す / 退ける / 回す を決める。回すものは編集しない。

| # | 工程 | ひとことで | 11 §4.7 との関係 | B |
|---|---|---|---|---|
| **F0 受け付け（新設）** | 差し戻しを拾い、HEAD を固定（`git ls-remote` と API の突合）、**指摘を全部開く**。指摘ごとに FX-1（直す）/ FX-5（退ける）/ FX-6（回す）の仕分けを 1 行で決める。回すものは**編集しない** | 26 V0・V1 の軽い版。GQ qm-session §Authoritative HEAD（I-13） | B-F1・B-F11・B-F13 |

- **受ける上限**: 核の「受ける上限」の 4 条件（具体性・局所性・領域・種類）を指摘ごとに当てる。1 つでも外れたら「回す」（宛先は付表 3a）
- **成果物**: 指摘ごとの仕分け表（id / 直す・退ける・回す / 理由 1 行）。`.fix-state.md` に書く
- **典型的な失敗**: 指摘を読まずに直し始める / 方針の指摘を自分で直す / 2 周目の同じ指摘を 3 周目に進める
