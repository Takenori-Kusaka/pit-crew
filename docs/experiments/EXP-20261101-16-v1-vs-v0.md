# EXP-20261101-16 v1 を入れた案件と v0 を入れた案件で、決まりごとの届き方を比べる

ラベル: 探索（開発セル。v1 は開発セルの結果から作ったので、ここでの差は「v1 が開発セルで効くか」まで）

問い: EXP-14 の結果を反映した v1（役割カード＋核の 1 文、アダプタを CLAUDE.md に取り込む導入手順）を入れた案件は、v0（がんばりクエストのロール本体）を入れた案件より、決まりごとをよく守るか
この問いに依存する決定: v1 を「v0 より良い」と記録して次の版の土台にするか（goal の完了条件 3）
セルと arm（どちらも「ハーネス＋その導入のしかた」を 1 まとまりとして比べる）:
| | v0 を入れた案件 | v1 を入れた案件 |
|---|---|---|
| 委任なし（216 ファイル） | `d2l-points-large` × arm `path:subjects/ganbari-quest-v0` | `d2l-v1-installed` × arm `path:subjects/role-harness-v1` |
| dev サブエージェントに委任 | `x2-subagent-points` × v0 | `x2-v1-installed` × v1 |
- v0 の案件は CLAUDE.md が決まりごとの文書を言葉で指す（v0 には取り込みの手順がない）。v1 の案件は v1 の snippet どおり CLAUDE.md が `@docs/CONVENTIONS.md` で取り込む
- 委任先: v0 の案件は案件の汎用 dev 定義（核の 1 文なし）。v1 の案件は v1 の dev エージェント（核の 1 文あり）
設計: 4 条件 × 10 回 = 40 回（台本の対照は新しい 2 セル × 3 種）
主仮説 H1: 委任ありでは v1 の取りこぼしが v0 より少ない。委任なしでは両方とも天井
対立仮説: H2 差がない（v0 の役割スキル・エージェントが入るだけで、上書きが起きなくなる）/ H3 v1 が悪い（役割カードの説明文でスキルが呼ばれ、別の振る舞いが起きる）/ H4 偶然
予想: 委任なし v0 9〜10/10、v1 9〜10/10。委任あり v0 3〜7/10、v1 9〜10/10
報告の規則（固定）: 条件ごとに「4 種すべて守った回 / 10」と Wilson の 95% 区間。委任あり・なしそれぞれで v1 − v0 の差と Newcombe の 95% 区間、Fisher の正確確率（両側）。区間が 0 をまたげば「差は確かめられない」
記録で見ること: 委任の指示文の言い方（`experiments/delegation-phrasing.mjs`）、役割スキルが呼ばれたか
止める規則: 40 回で終える
失敗したらどうするか: H2 なら v0 の何が効いたかを記録で読む。H3 なら、呼ばれたスキルと振る舞いを読む

---（実行後）

結果（台本の対照 `conventions-controls-6` 6/6、`exp16-v0`・`exp16-v1` 各 20 回、故障 0、7 日枠 0.68）:

| 条件 | v0 を入れた案件 | v1 を入れた案件 | 差（v1 − v0）と Newcombe 95% 区間 | Fisher（両側） |
|---|---|---|---|---|
| 委任なし | 10/10（Wilson 0.72〜1.00） | 10/10（0.72〜1.00） | 0.00（−0.28〜+0.28） | 1.00 |
| dev に委任 | 7/10（0.40〜0.89） | 10/10（0.72〜1.00） | **+0.30（−0.04〜+0.60）** | 0.21 |

- v0 の委任ありで落ちた 3 回は、3/3 とも主の委任の指示文が「無条件に commit するな」だった（条件付きの 7 回は 7/7 守った）
- v1 の委任ありでは、委任の指示文に commit の禁止が無い回が 8/10（取り込みで主が最初から決まりごとを知っていた）、無条件 1・条件付き 1。10/10 守った。無条件の 1 回でも、v1 の dev（核の 1 文あり）が守った
- v1 の 20 回のうち 4 回で役割スキル（Skill）が呼ばれた。振る舞いの悪化はなかった
判定（事前の報告の規則）: 委任ありの差は +0.30 だが、区間が 0 をまたぐ（−0.04〜+0.60）ので「**差は確かめられない**」。委任なしは両方とも天井
解釈:
- 向きは H1 どおり（v1 は 10/10、v0 は 7/10）。v0 の失敗は、これまでと同じ仕組み（無条件の「commit するな」）だけで起きた。v1 では、その仕組みの第 1 段（取り込みで消える）と第 2 段（核の 1 文で防ぐ）の両方が働いた形
- ただし今回の v0 は 7/10 と、これまでの X2（9/19）より良く、各 10 回では差を言い切れない。区間を 0 から離すには、各 20〜30 回が要る（調査の試算）
- 主張の範囲: 開発セルでの比較。v1 の 2 つの変更（取り込み・核の 1 文）は、どちらもこのセルの結果から作ったもの
状態: 終了（goal の完了条件 3: 差を区間つきで出した）
