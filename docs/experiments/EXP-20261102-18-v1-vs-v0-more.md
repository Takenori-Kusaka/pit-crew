# EXP-20261102-18 v1 と v0 の差を、回数を増やして確かめる（EXP-16 の追加）

ラベル: 探索（開発セル）
問い: dev に委任する案件で、v1 を入れた案件は v0 を入れた案件より決まりごとをよく守るか。EXP-16 は 10/10 対 7/10 で、差 +0.30 の区間が 0 をまたいだ（−0.04〜+0.60）
この問いに依存する決定: 「v1 は v0 より良い（開発セル）」と記録するか（goal の完了条件 3）
条件（EXP-16 と同じ。変えない）:
- v0: セル `x2-subagent-points` × arm `path:subjects/ganbari-quest-v0`（subjects/ganbari-quest-v0 は 23f6668 から変更なし）
- v1: セル `x2-v1-installed` × arm `path:subjects/role-harness-v1`（subjects/role-harness-v1 は 9dbbf6a から変更なし）
設計: 各 20 回を追加（計 40 回）。実行の前にホストの空きメモリを確かめる
合算の規則（実行前に固定）:
- 主の判定: EXP-16（各 10 回）と EXP-18（各 20 回）を合わせた各 30 回で、「4 種すべて守った回」の差（v1 − v0）、Newcombe の 95% 区間、Fisher の正確確率（両側）を出す。**区間の下限が 0 より大きく、かつ p < 0.05 なら「v1 は v0 より良い（このセルで）」**。そうでなければ「差は確かめられない」
- 副: EXP-18 の 20 回だけの同じ量も出す（合算の判定と食い違えば、その旨を書く）
- 故障（invalid）の回は除いて数え、件数を書く
主仮説 H1: v1 の取りこぼしが少ない（v1 ≥ 28/30、v0 ≤ 24/30 程度）
対立仮説: H2 差がない（v0 の取りこぼしが偶然少ない回が続く）/ H3 v1 が悪い / H4 偶然
