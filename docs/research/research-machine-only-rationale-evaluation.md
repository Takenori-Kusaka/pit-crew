調査日: 2026-11-04〜05 / 対象: pit-wall の E 系列（判断の理由と代替案の質: R2・R4・R5・S2）と工程の中身の質を、**人の判定も人のラベルも使わずに**測り、測り方そのものも人を入れずに検証する方法
きっかけ: オーナー（2026-11-04 夕）「人間が評価しなければならなくなった時点で評価基盤としては破綻」。人のラベルで judge を検証する案（設計書 23 §4・§5 の「人の抜き取り」、`research-human-labels-for-judges.md`）を却下（`docs/log/2026-11-02.md` 末尾）
目的との関係: 成果物 1.1（主な量 = 規定したプロセスへの準拠と根拠の裏付け）の E 系列を、人を入れない測り方に置き換える。`docs/planning/00-goal-charter.md`

## 結論（先に）

1. **「文章の良し悪しを judge に聞く」をやめ、「判断の点ごとに 4 つの量 ＋ 欠陥の不在」を測る形に変える。** 4 つの量 = (a) 選んだ案は正しかったか（植え込んだ判断の点の正解を最終状態から決定的に判定）、(b) 書いた理由は内部で整合しているか（構造の推論・論証の受理可能性・非劣性、決定的）、(c) 理由だけを読んだ別のモデルが同じ案を選べるか（simulatability の差分、ローカルの 8B で測れる）、(d) 理由は結論に効いていたか（判断の点の前後からの再実行で正解率が動くか、標本抽出）。これらはいずれも人のラベルを前提にしない [推論、根拠は §3〜§4]
2. **人を入れない「正解」は 3 種類しかない: 構成で決まるラベル、植え込んだ正解、関係（不変・単調）。** 良い成果物に決定的な編集を 1 か所加えた「悪い版」のラベルは編集から導かれる（Ballı ら 2026: 決定的摂動で作った負例は gold との文字列比較で 100% 検査できるが、LLM が書いた負例には機械的な整合性検査が無い [一次・要旨]）。植え込んだ判断の点の正解は最終状態から判定できる（Math-Shepherd / OmegaPRM が「正答が確かめられる課題」を前提に、人のラベル無しで工程の質を定義したのと同じ構成 [一次]）。メタモルフィック関係（書式を変えても判定は変わらない・決め手の観察を消せば R4 は落ちる）は CheckList の INV / DIR と同じで、ラベル無しのデータに使える [一次]
3. **judge の多数決やその一致率は、検証には使えない。** Dawid–Skene 系・スペクトル法・弱教師の label model はすべて「判定器の誤りが真値を条件に独立」を仮定する。同じ証拠束・同じ指示を見る LLM の陪審はこの仮定を破り、共有する癖のある側が「正確」と推定される（Said & Villaneau 2026: Dawid–Skene が GPT-5.2 の精度を 90.7% と推定、人の gold では 71.0%、順位も逆転 [一次・要旨]。Balasubramanian ら 2026: 条件付き独立を仮定する手法は依存があると「自信を持って誤る」[一次・要旨]）。「全員が一緒に誤る」と「全員が一緒に正しい」は観測上区別できない。段 0c で 8B の陪審が TNR 0〜0.33 だったのは、多数決で救えない構造的な事実 [推論]
4. **抽出器の形依存（EXP-39 / 40 の失敗）は、正規表現を増やしても直らない。構造を宣言させるか、抽出を機械で検証可能にするかの二択。** SE の文献で人のラベルに頼らず機械的に根拠の質を推論した唯一の系統は SEURAT（Burge 2005）の 16 の推論（選んだ案に賛成の論拠が無い・反対しかない・同じ論拠の重複・トレードオフの片側欠落 等）で、前提は「根拠が構造化されている」こと [一次]。自由文からの抽出は、代替案・却下理由・決定の精度が 0.15〜0.45 にとどまり（Alkadhi ら 2018・Argus 2026・Pirouzkhah ら 2026 [一次]）、プロジェクト間で転移しない（Mahadi ら 2020 [一次・要旨]）。抽出を使うなら、引用の実在・件数・**同じ内容を表 / 箇条書き / 散文に機械で描き直して結果が不変**・系統の違う 2 モデルの一致（不一致 = 棄権）で検査する [推論、根拠は §3.1]
5. **ベクトル・情報量の検出器は「欠陥の不在」を証明でき、「質の存在」は証明できない。** 定型の代替案は課題との条件付き PMI ≈ 0（Li ら 2016 の MMI の動機 [一次]）、規則文の鸚鵡返しは log p(r | 課題+規則) − log p(r | 課題) の差で測れる（Mahmoud ら 2026 の self-internalization gap を役割を変えて使う [一次]）、重複する案は類似度行列の固有値のエントロピー（Vendi score = 実効的な案の数 [一次・要旨]）で数えられる。ただし埋め込みは否定・反義に鈍い（HEROS・NevIR [一次・要旨 / 二次]）ので「方向が違う」は低い類似度では測れず、NLI の矛盾判定を併用する
6. **人のラベルの代わりに「植え込んだ正解への予測力」で測り方を検証する。** 根拠の質の代理指標は、セル横断で (a) の正解率を予測できなければ plausibility（人に説得的なだけの性質）であり捨てる。Chen ら 2023: LLM の説明の simulation precision と人の plausibility 評価の相関は Pearson 0.012 [一次]。Jacovi & Goldberg 2020: 忠実性の評価に人の判定と人の gold ラベルを使うべきでない [一次]。VeriCoT 2025: 形式検証を通った推論は通らないものより正答率が高い（ProofWriter 精度 94.1% 対 課題正答率 75.8%）[一次] — この「検証通過 → 正答率が上がる」が、人を入れない検証の型
7. **残る限界は 5 つで、どれも隠さず報告に書く**（§7）: 実行できない前提の真偽 / 案の集合の完全性 / 実データ上の judge の絶対精度 / 欠陥の出現率 / 閾値。「判定の台本（どの編集が『R4 が落ちる』を意味するか）」を書くのは人の 1 回限りの判断で、これは消せない。コードとして版管理・差分検査する

## 1. 問題の整理

### 1.1 何が壊れたか（EXP-39 / 40、段 0c）

- 検出器: `自明[:：]` の形だけを数えて 16/30 を 0 と判定、「判断の点」ブロックの 14/30 を表・散文のため取りこぼし、`.gitignore` 書き込みで窓が閉じた。**形で拾う限り、書き方を変えた arm が不利になる**（Q4 の公平の原則に反する）
- エージェントの逃げ: 「案 2 つ以上、無ければ『自明: 理由』」の 2 択で 16/30 が自明を選び、評価側が「自明でない」と登録した点に対して比較を書かない
- judge: Claude haiku 単独は台本 6 件で満点だが被験体と同系統。8B 陪審は悪い成果物を met と判定（TNR 0〜0.33）、Granite は引用の作話で 5〜7 割が無効。人の抜き取りで較正する前提だった

### 1.2 「人を入れない」の読み方（本調査の立場）[推論]

禁止されるのは**人の判定を測定値や検証の gold にすること**。以下は人のラベルではない:

| 許される正解の種類 | 根拠 |
|---|---|
| **構成で決まるラベル**: 良い成果物に決定的な 1 編集を加えた版の期待判定は編集から導かれる | CheckList の INV（ラベルを変えない摂動）/ DIR（決まった向きに変わる摂動）は「ラベル無しのデータで検査できる」[一次、Ribeiro ら 2020]。Ballı ら 2026: 決定的摂動の負例は gold との文字列比較で 100% 検査でき、LLM 生成の負例にはそれが無い [一次・要旨] |
| **植え込んだ正解**: 評価側がセルに置いた判断の点の正しい選択肢は、最終状態から決定的に判定できる | Math-Shepherd: 工程の質を「そこから正答に至る可能性」と定義し、N=8 の完走で推定（人の注釈なし）[一次、設計者照合]。OmegaPRM: 同じ量を二分探索で求める [一次]。前提は「正答が確かめられる課題」で、植え込んだ判断の点はそれに当たる |
| **関係**: 書式・順序・言い換えで判定が変わらない（不変）、決め手を消せば落ちる（単調） | メタモルフィックテストはテストオラクル無しで使える手法 [二次、Chen ら 1998]。JRH（RAND、2026）: 書式不変・言い換え・冗長化・ラベル反転の検査群 [一次] |

残るのは「どの編集が『R4 が落ちる』を意味するか」を決める台本の作成で、これは人のルーブリック解釈の 1 回限りの判断。**コードとして**版管理し、差分で整合性を検査する（§7）。

### 1.3 既に決定的に取れているもの（土台）

`packages/pit-wall/src/graders/process/`: 事象表（`events.mjs`）、書いた全テキストの時刻付き抽出（`authored.mjs`）、見えていたもの O/P/M/N/X/U と支持 S1（`visibility.mjs`・`grounding.mjs`）、工程の先行関係（`phases.mjs`）、arm を伏せ書式を剥がした証拠束（`judge/bundle.mjs`）、引用の実在検査（`judge/jurors.mjs`）。本調査の設計は、この土台の上に**判断の点ごとの構造**を足し、judge を主役から外す。

## 3. 提案する測定設計（pit-wall の E 系列、人のラベル無し）[推論]

### 3.1 判断の点ごとの出力

事前登録した判断の点 1 件につき、次を出す。judge の met / not-met の単一値は出さない。

| 欄 | 中身 | 層 | 判定 |
|---|---|---|---|
| **correct** | 選んだ案は植え込んだ正解か（最終状態の述語） | L0 | 決定的 |
| **mentioned** | 植え込んだ代替案を案として挙げたか / 「自明」と宣言したか | L1 | 決定的（抽出後） |
| **coherent** | S1・S2・M3・M4・M10 の違反数、基礎付き拡張に採用案の論拠が入るか、非劣性 | L1 | 決定的 |
| **grounded** | 決め手が参照する観察の O/P/N/X と、理由より前に見えていたか | L1 | 決定的（既存） |
| **defects** | 特異性 ≈ 0 / 規則依存の差が大 / 実効案数 < 2 / 被覆 0 / run 横断の反復 / NLI 矛盾 の各フラグ | L2 | 機械的 |
| **communicable Δ** | 読み手モデルが理由だけから採用案を選ぶ率 − 理由なしの率、および正しい案を選ぶ率 | L3 | 行動（ローカル 8B × 2 系統、n 回） |
| **causal Δ** | 理由の前後からの MC 再実行で P(correct) が動くか（標本） | L4 | 行動（高価） |
| **unverifiable** | 実行も観察もできない前提（好み・保守性）の数 | L1/L2 | 区分（減点しない） |

読み方の中心は **2×2（coherent × correct）**: 「整合だが誤り」= 自信のある合理化（Turpin ら 2023 の型 [一次・要旨]）、「不整合だが正解」= 別の所で決めた post-hoc（Lanham ら 2023 の型）。前者は L4 で causal Δ を測る標本の優先対象。

### 3.2 層ごとの妥当性の論拠と、ごまかしの検出

| 層 | 妥当性の論拠（人無し） | ごまかし | 検出 |
|---|---|---|---|
| **L0 植え込み正解** | 構成による正解。Math-Shepherd / OmegaPRM の「正答が確かめられる」前提に相当 | 無し（最終状態の述語）。ただし植え込んでいない判断は測れない | 植え込んだ点を増やす。評価側が独立に列挙（設計書 23 §2.4） |
| **L1 構造・論証・裏付け** | 定義的（SEURAT の推論は人のラベルで検証されていない: 定義だから）。Dung Thm 30 で非巡回なら一意。O/P/N/X は transcript から決定的 | 整合した物語を誤った選択の周りに書く / 却下案に filler の con を足す / 自己申告の引用 | 2×2 で L0 と交差。filler の con は #14（特異性）と #4（探針）が落とす。引用は O でなければ数えない（既存） |
| **L2 ベクトル・情報量** | 各成分が狙う欠陥に**証明可能に**反応する（重複 → Vendi 不変、定型 → PMI ≈ 0、未観察 → 被覆 0、規則依存 → 差が正）。植え込んだ欠陥（案を複製 / 定型 3 案に置換 / 規則文を貼る / 見ていないパスに差し替え / 比較を消して「明らかに最善」）で、狙った成分だけが大きく動くこと（判別的妥当性、Campbell & Fiske 1959 の MTMM の考え方 [二次]） | 課題のトークンを定型に散らす（特異性↑） / 規則を自分の言葉で言い直す（差↓） / 無関係な定型 3 案（多様性↑） | 成分の AND と相互検査: 特異性 × ツール出力への被覆、多様性 × 特異性、差 × shingle 重なり。成分間の相関構造が arm 間で同じであること（測定不変性）を #19 で検査 |
| **L3 読み手モデル** | Pruthi の論拠（説明は訓練時だけ ⇔ 採用案は伏せる）、Chen の LLM 代理の κ が人同士と同程度、ALMANACS の完全自動 | 読み手が課題を自分で解く / 案名で写像を漏らす / 「X が最善」の連呼 | リポジトリを渡さない、案名を毎回入れ替え、退化した理由の基線（結論 1 文）が対照に勝たないこと、採用の記述を剥がす（既存 `hideAdoption`） |
| **L4 MC 再実行** | 凍結した接頭辞からの再実行は偽れない。理由の前で MC=1 なら post-hoc と判定 | 理由より早く決める → 検出されるだけ | 二分探索で「実際に決まった工程」を見つけ、理由が主張する位置と比べる（既存の visibility で「何がいつ見えたか」は取れる） |
| **judge（残すなら）** | #20 の構成ラベル TPR/TNR（演算子ごと）、#21 の安定、#22 の制約整合、#23 の arm 差分の 3〜4 数で報告し「精度」と呼ばない | 偽引用・自己申告・書式（既存の摂動 9 種） | 既存の正規化 + 引用実在検査を維持。**Dawid–Skene で検証しない** |

**層を跨ぐ検証の規律**: L1〜L3 の各代理指標は、セル横断で L0 の correct を予測できなければ捨てる（VeriCoT の「検証通過は正答率を上げる」が型 [一次]。Doshi-Velez & Kim の「機能的に基礎付けた代理は一度は行動 / 人で錨を打つ」の、人を行動に置き換えた形 [一次]）。これが、オーナーが却下した「人のラベルで judge を検証する」の置き換え。

**Goodhart の見張り**（設計書 23 §6 を強化）: E 系列だけ上がり B 系列と害が動かない arm は過程の演技を疑う（既存）。加えて #13 の規則依存の差が arm 間で大きく違えば、差の大きい arm の E の上昇は「規則を知った効果」として分けて報告する。

### 3.3 「自明」の扱い

評価側が「自明でない」と登録した判断の点に対する「自明」宣言は、L1 で mentioned=false として決定的に数え、R2 相当は not-met。L0 の correct は独立に出るので、「自明と書いて正解だった」は 2×2 の「不整合（比較無し）× 正解」に入る。宣言の文言（`自明:` か `自明と判断` か）は抽出（#11）が吸収し、形で数えない [推論]。自明な判断に根拠を求めない原則（前の調査 §4.1）は、植え込んでいない点に根拠を書いても加点しないことで保つ。

| **1** | **判断の点の正解述語**（L0）: `heldout-s5` / `d3` の `decision-points-detail.json` に「どの案を選んだか」を最終状態から判定する述語を足す（既存の害の述語と同じ型: 参照実装の差し替え・grep・テスト実行）。植え込む代替案は「既存を使う / 作らない」系を必ず 1 つ含める | 参照解（正解の案）で correct=true、台本の誤った案（既存の `harmful` 台本に相当）で false。述語が両方で動かないセルは捨てる（05 §4.2 の捨てる規則） |
| **2** | **書式に依存しない抽出**（#11）: ローカル 8B に JSON スキーマ {decision, options[{text, adopted, pros[], cons[]}], criteria[], trivial_claim} を出させ、引用の実在・件数で後検査。EXP-39 / 40 の失敗の直接の修理 | **書式不変の台本**: 合成した理由 1 件を、表 / 箇条書き / 散文 / 日本語 / 英語 / 「自明と判断」の各表記に機械で描き直し（`validation-set.mjs` の harness 描画と同じ要領）、抽出の多重集合が一致。2 系統（Qwen3 と Granite）で一致しなければ棄権として数える。既存 runs（EXP-39 / 40 の 160 試行）を regrade して、取りこぼしていた 14 件が拾えるかを**探索として**見る |

## 6. 費用 [推論]

- L0〜L2・#20〜#22: モデル呼び出し無し、または ollama / llama.cpp のローカル推論（bge-m3 1.2 GB、MiniCheck-FT5 ≈1.5 GB、Qwen3-8B Q4 ≈5 GB は同時に載らないので順に）。追加支出なし
- L3: 判断の点 1 件あたり 8B の呼び出し 3〜6 回 × 2 系統 × n 標本。EXP-32 規模（判断の点 ≈ 400）で数千回、GPU 時間のみ
- L4: 標本 1 件あたり agent の続行 k=8 × 2 点 = 16 本。Claude 枠を消費するので、2×2 の対角外の標本 10〜20 件に限る。7 日枠の規律（憲章）に従う
- 立ち上げの台本: 判断の点の述語（セル数分）、合成理由の描き直し（1 件 × 6 表記）、変異演算子 6〜8 種。いずれも一度書けば regrade で何度でも回る

## 7. 人を入れずにできないこと（正直な限界）

1. **実行も観察もできない前提の真偽**（「保守しやすい」「チームの好み」）。形式論証も Z3 も前提を公理として受け取る（Amgoud & Prade: K は入力 [一次]）。→ 「検証不能」として数え、採点しない
2. **案の集合の完全性**。植え込んだ代替案を挙げたかは判定できるが、誰も思いつかなかった良い案の欠落は見えない（SE の抽出研究でも代替案が最も精度の低い要素 [一次]）
3. **実データ上の judge の絶対精度**。一致・安定・変異検出率のどれも「全員が一緒に誤る」を見分けない。Garg ら: 精度の同定は最適な予測器の同定と同じ難しさ [一次・要旨]。報告は「演算子 N 種で TNR ≥ x、書式・順序で安定 ≥ y、非 Claude judge との arm 差分 ≤ z」までが正直な上限
4. **欠陥の出現率**。合成・変異の台本は検出率を与え、本番での頻度は与えない（Husain [一次]）。頻度は実 run の regrade で、検出器の限界込みで報告する
5. **閾値**。特異性・多様性・Δ の切り方は自前の分布から決める慣習で、検証された境界ではない。→ 絶対値でなく「前の版の同じセルより悪くない」のラチェットで使う
6. **NLI の輸入**。使える事実照合モデルは全て人のラベルで較正され、コード領域を含まない。在領域の NLI を作るなら、Steiner & Zhang が commit 履歴から弱教師で作ったように、後の編集・テスト結果から整合ラベルを掘る（人の注釈ではない）[一次]
7. **狭義の忠実性**（内部の因果）。重みの無い Claude では CC-SHAP 型の帰属はできず、測れるのは出力レベルの自己整合（Parcalabescu & Frank [一次・要旨]）。L4 の行動的な因果の寄与が最強の代理で、Jacovi & Goldberg はそもそも人がそれ以上を判定できないと論じる [一次]
8. **台本を書くこと自体**。「この編集は R4 の否定を意味する」はルーブリックの解釈で、人が 1 回決める。SANE（NeurIPS 2026）はこれを agent に委ね、LLM の検証器を足す — 負例の整合性の問題を台本の段に移すだけ [一次・要旨]。コードとして扱い、版・差分・反証可能性で管理する
9. **8B の陪審の救済**。負例で偶然以下の判定器は、一致モデルに入れても haiku の精度を推定できない（独立な負例の信号を持たない）。改善を示せる唯一の手段は #20 の構成ラベル TNR で、それが既に「使えない」と言った

## 8. 見つからなかったこと・未確認

- コーディング agent の自由文の理由を対象に、人のラベル無しで質を検証した研究は見つからなかった。最も近いのは数学の PRM（植え込んだ正答）と VeriCoT（形式検証 → 正答率）
- 根拠の**質**（存在でなく）が後の revert・侵食・再作業と相関することを示した野外研究は見つからなかった（存在と merge・欠陥の相関のみ: Li & Ahmed 2023 [一次・要旨]、Pirouzkhah ら 2026 [一次]）
- ルーブリックの語の鸚鵡返しを**文字列重なり**で検出することを検証した研究は無い。Mahmoud らの hack は「基準の文面を満たして全体の質を落とす」型で、語のコピー型ではない
- 埋め込みの反義・否定への鈍さをコード系の文で測った数値は無い（IdBench は識別子のみ）
- Dawid & Skene 1979 の原文（JSTOR 403）、Dung 1995 の出版社ページ（403、著者 PDF で代替）、Platanios ら 2014 の PMLR ページの要旨（文字数制限で全文は未取得、auai.org の PDF で代替）
- tavily MCP はこの調査で全呼び出しがタイムアウト。取得は WebFetch / WebSearch / pdftotext のみ
