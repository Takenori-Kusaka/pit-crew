## 2. 何が分かったか

### 2.1 主張（事前登録、EXP-42、開発セル 8 × 4 arm × 10 回）

**既定の QM スキルは、プロセス準拠 B（判定の前に受入基準・設計書・変更ファイル・検査の証拠を開き、順序を守り、権限外を回し、レビュー対象を編集せず、承認者を分け、委譲しない行動の割合）を 3 つの相手より上げる。**

| 比較 | B share の差 | 区間（1 − 0.05/3） | 判定 |
|---|---|---|---|
| default − ハーネスなし | +0.058 | [0.026, 0.085] | RAISES |
| default − GQ 丸写し（v0） | +0.051 | [0.013, 0.088] | RAISES |
| default − 最初の汎用版（v1） | +0.110 | [0.077, 0.141] | RAISES |

水準: default 0.841 / vanilla 0.783 / v0 0.790 / v1 0.731（n = 78〜80）。差は Dev の EXP-32（0.35 → 0.92）より小さい。レビューは「読んで判定する」行動がハーネスなしでも 0.78 まで出る仕事で、差が出るのは **出荷判定**（default だけが含まれる変更の判定記録を開いて判定に至る: h1 10/10・h2 9/9 対 他 arm 0〜8/9）と、`issue-opened`（vanilla / v1 は受入基準を開かない 68 / 65 回）。

### 2.1b 保留セルでの一般化（EXP-43、2026-11-05、別の作成役・別の題材、12 セル × 4 arm × 10 回）

**保留セルでも同じ向き・同程度の差で RAISES × 3**: default − vanilla +0.050 [0.028, 0.069]（vanilla は出荷セルが無効超過で除外され review 9 セルのみ）/ default − v0 +0.044 [0.013, 0.076] / default − v1 +0.090 [0.068, 0.117]。水準 default 0.860 / vanilla 0.810 / v0 0.816 / v1 0.769。害は差なし。天井 6/12（権限外の問い 2 つを含む）。出荷セル 3 つは default だけが 9/9。**通してよい PR の 1 つ（qmh-f2）で default が止めすぎ 7/10** = 開発セル（qm-f4）と同じ型が再現 → 第 3 版の最有力の候補。詳細は `docs/experiments/EXP-20261105-43-qm-heldout.md`
