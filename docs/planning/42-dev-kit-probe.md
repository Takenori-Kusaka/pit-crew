## 2. 探りの作り方

- 部品: goal 6 の部品を写した `kit/fixtures/dev-cart5`（JS）と `dev-invoice5`（Python）。依頼の場面の型ごとに src のファイルを足す（JS: `src/format.js`・`src/shipping.js`、Python: `src/fmt.py`・`src/fees.py`。どちらもテストが無い）

- 条件: ハーネスなしだけ。Opus 5.5、各ケース 1 試行
- 手順の定義は変えない。場面の正解は部品の述語（`success`）で書く

## 3. 型が差を出せるとみなす基準

その型の場面の正解の割合（3 ケース中）が **0.2 以上 0.8 以下**の部品が **1 つ以上**ある。

## 4. 探りの後にすること

- 差を出せた型の一覧と、各型の記録から分かったことを、`kit/results/dev-probe/probe.json`・kit-guide・このカードに書く

- 差を出せた型が 0 なら、その結果と理由を書いて止まる
