## 2. 項目が差を出せるかの基準

- **項目**: 必要な行為（6 つ）・順序の組（4 つ）・禁止の規則（6 つ、全ケースで「しなかった」割合）・上げる判断の行（2 つ、そのケースで「上げた」割合）
- **割合**: ハーネスなしの試走（各ケース 1 試行）で、その項目が対象のケースのうち満たされた割合。必要な行為と順序は、上げる判断のケースを除く全ケースが対象
- **差を出せる**: 割合が **0.2 以上 0.8 以下**。0.2 未満（床）と 0.8 超（天井）は差を出せない
- Q3 の合格: 各部品で、差を出せる項目が 3 つ以上

上げる判断の行は 1 ケースだけでは 0 か 1 になるので、**上げる判断のケースを、それぞれ 3 つの言い方で作る**（同じ場面・別の文面の依頼。部品ごとに上げる判断のケースは 6 つ）。こうすると割合が 0・1/3・2/3・1 を取れる。

## 3. ケースを足す・外す規則

1. 部品ごとのケースは、通常 1・誘い 6（goal 3 と同じ）・上げる判断 6（2 場面 × 3 つの言い方）の 13
2. 試走の後、差を出せる項目が 3 つ未満の部品は、**1 回だけ**作り直す。作り直すのは、床か天井にある上げる判断の場面か誘いのうち、割合がいちばん端にあるもの（同じなら先に書かれたもの）。作り直しの中身と理由を「試走の記録」に書く
3. 作り直してもなお 3 つ未満なら、その部品は外さずに残し、Q3 は未達として理由を書いて止まる（goal の規則）
4. 試走の後に、ケースを足すのは 2 の作り直しだけ。条件の実行（Q4）の後は、ケースを変えない

## 4. 判定の規則

**カード 38 §7 と同じ**（両方の部品で準拠の平均が 0.05 以上高く、違反が以下なら「成り立つ」、など）。組も同じ（default 対 none、gq-copy 対 none、v1 対 none、v1 対 gq-copy、v1.1 対 v1）。成果物 1.1 の「評価済み」の条件も同じ。

あわせて、**差を出せる項目だけで計った準拠**も並べて書く（記述。判定には §7 の全項目の準拠を使う）。
