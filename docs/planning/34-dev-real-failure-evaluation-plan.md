## 4. 4 つの条件

依頼文は全条件で同じ形（issue の題名と本文 + **環境の事実**）。道具・権限・上限も同じ。

| 条件 | 作業木 | 履歴 | スキル・道具 |

| **B 要求だけ** | A + 要求の文書（`CLAUDE.md`、git から隠す） | A と同じ | なし |
| **C 既定スキル** | A と同じ | A と同じ | `subjects/dev-skill-default/skills`。入口は `/dev` |
| **D GQ そのまま** | 直前の commit の全ファイル | 直前の commit まで。**書き換えない** | 木の中の GQ のスキル・設定・hook。gh の代役。graphify |

- **除くもの（A・B・C。`34-review-g5.md:500-508`）**: `CLAUDE.md`（全階層）、`.claude/`、`docs/sessions/`、`.github/copilot-instructions.md`、`graphify-out/`、`**/AGENTS.md`、`**/GEMINI.md`、`.claudeignore`、`.geminiignore`、remote。**`.husky/` は全条件で残す**（案件の道具）。設計書・ADR・CI・検査の台本も残す。線は「エージェントに向けた指示ファイルか」。課題ごとに、実際に除いたパスを記録する。
- **A の意味**: 「何も知らせない」ではなく「**指示ファイルで知らせない**」。設計書・ADR・CI の中に手続きの規則は残る。主張の文にそう書く。
- **履歴（決定 10）**: 全条件で、修正が**物として無い**こと。確かめること（G4。機械）: (1) 修正の commit とそれ以降の commit・タグ・ブランチ・reflog・どこからも指されない object が無い。(2) 修正後のファイルと隠した検査の中身に当たる object が、どの条件の履歴にも無い。(3) A・B・C で、除いたパスの中身がどの object からも戻せない。(4) 書き換えた履歴でも、commit の日付と文は元のまま。**履歴の深さ（全部か、浅くするか）は 未定**: GQ は 940 MB [査読]。実装役が測り、査読役が決める。全条件で同じ深さにする。
- **C（`34-review-g5.md:524`）**: `dev-skill-default` は `subjects/dev-structure/MskillD1` と中身が同じ（`diff -rq` で差なし [査読]）。入口は EXP-32 と同じ `/dev`。
- **B の要求の文書**: §5 の項目表を見ない役が、既定スキルの「出る条件」（`dev/SKILL.md:90-215`）から書く。直さない。別の役が対応表を作るだけ。文書に対応が無い項目は C − B から外し、C − A には残す。**まだ無い。**
- **必ず記録するもの**: 4 条件の指示の文字数、C の Skill の呼び出し率、B の文書と C のスキルが文脈に入った事実、条件ごとの履歴の命令（`git log`・`blame`・`show`）の数。

**D（決定 11）**

## 8. 統計と判定の規則（決定 1・5・7）

- 課題の中で対にする。単位は課題。課題 × 条件の値は試行の平均。区間は、課題ごとの差に対の t と、符号を入れ替える並べ替え検定。副に階層ベイズ。
- **順（固定）**: まず C − A。C − A が「上げる」のときだけ C − B に判定を付ける。

| 語 | 規則（**97.5% の区間**。各段 2.5%） |
|---|---|
| 「上げる」 | 区間の下限 > 0、かつ点推定 ≥ δ、かつ §5 の符号の条件 |
| 「δ 以上は上げない」 | 区間の上限 < δ |
| 「この範囲では決められない」 | それ以外。区間を付けて書く |
| 言わない | 「δ 以上の差は無い」「同等」 |

- 1 段目の途中では値を見ない。
- **2 段目（`34-review-g5.md:389-402`）**: 判定を付ける対比の結果が「決められない」のときだけ、1 回。足すのは課題で、1 段目と同じ数、合計の上限 30。**新しく通った課題が 8 未満なら行わない。「決められない」のまま書く。見込みでは行えない**（§3）。行う場合: 条件は A・B・C。1 段目と合わせた全課題の差を重みなしで 1 つに合わせる。1 段目で C − A が「上げる」なら確定で、判定し直さない。モデルの id・スキルの版・採点器の版・上限・試行の数が 1 段目と同じでなければ合わせない。段ごとの点推定と区間を並べる。G3 はやり直さない。3 段目は無い。
- **この規模で言えること**（仮定つき。`34-review-g5.md:245-249`）: 15 課題 × 2 試行で、見える差は標準偏差の約 0.62 倍。C − B は過去 +0.04〜+0.09 の側と見るのが自然で、**いちばんありそうな結末は「決められない」**。2 段目が行えないなら、そのまま終わる。
- 言わないこと: GQ 以外・別の難しさ・名指しの無い依頼への一般化。どの種類の課題で効くか。差が見えなかった項目を「上げられない工程」の代わりにすること。EXP-32 の再現だという読み。
