# 08 計画の立て直し: 前提を疑う実験の順序（提案）

作成: 2026-11-01 / 状態: **提案（オーナー確認待ち）**
根拠: `docs/research/research-experimental-method.md`（前提の棚卸し P1〜P14、実験カードの型）、`research-entry-and-runner-fit.md`、`research-reusable-role-harness.md`、`07-v1-and-cells.md`

## 1. 方針

- 07 の順（入口 → v1 → 受け渡し・境界 → 移植）は、**前に進めることを前提にした作る順**だった。オーナーの指摘（実験的なので前に進み続けられるとは限らない、前提を疑う）に従い、**崩れたら計画全体が倒れ、かつ崩れやすい前提**から、最も安い試験を先に当てる
- 実験は 1 つずつ「実験カード」（`research-experimental-method.md` の型: 問い / この結果で変える決定 / 主仮説と対立仮説 3 つ以上 / 予想 / 反証の条件 / 止める規則 / 失敗したらどうするか）を `docs/experiments/` に書き、**実行前に commit** する。これが事前登録の代わりになる
- 各実験に「探索」か「確認」かのラベルを付ける。開発セルで直した結果は、何回回しても探索

## 3. 全体の止める・方向を変える規則（調査の提案を採用したい）

1. 前提の一覧を週 1 回見直す
2. 方向を変える条件: P1 で「どちらとも言えない」が大半 → 目標を手引きと評価基盤に縮める。P2 で単一セッションが同等以上 → 問いを「どの条件で分離が効くか」に変える。識別力のあるセルが試作 3 回で 1 つも作れない → 小さな手作りセルという方法を見直す
3. 退行の合図: 直近の実験で「予想外の結果を採点器・セル・文言の修正で吸収した数」が「事前の予想が当たった数」を続けて上回ったら、修正を止めて前提の一覧に戻り、整理と調査をする
4. 止める条件: オーナーの合格条件（汎用評価基盤のテストケースであり、公開できる汎用ハーネスでもある）が、方向転換を経ても満たせる見込みがないと、期日に記録から言えるとき。止めても、評価基盤・実験ノート・空振りの記録は成果として残す
5. **期日と回数の上限はオーナーが決める**（続けたい側が決めると基準が緩むため）
